FITS Viewer

A free desktop app for browsing folders of FITS astronomy images. Open a folder and every frame appears as an auto-stretched thumbnail, in colour where the data allows, with the key header details alongside - so you can see what a night's data actually holds, and sort it, without opening a full processing suite.

First time opening it?

Windows: double-click the download. If Windows shows "Windows protected your PC", click More info then Run anyway (it appears because the app isn't commercially signed).

macOS: unzip the download, then right-click FITS Viewer.app → Open → Open. You only need to do this once; after that it opens normally.

Linux: right-click the .AppImage → Properties → Permissions → allow executing as a program, then double-click it.

What it does

See a whole session at once

Thumbnails use the same median/MAD auto-stretch approach as PixInsight's and Siril's screen stretch, so faint signal is visible straight away. Thumbnails are averaged down rather than subsampled, so star fields stay clean.

Colour where the data has it

Stacked RGB images, and raw sub-frames from one-shot-colour cameras (converted from their Bayer pattern), are shown in colour. Mono, multi-extension (e.g. Hubble) and gzip-compressed files are handled too.

Header details alongside

Target, filter, exposure, date, telescope, coordinates and field of view - from the plate-solve where there is one, otherwise estimated from focal length and pixel size.

Sort out the duds

Mark frames or whole folders and send them to the Recycle Bin / Trash in one go. Nothing is ever deleted permanently, and the confirmation lists exactly what's inside each folder first.

Find your way around

Favourites, an Up button, and folder tiles that preview the first image inside - handy for archives and observing runs split across many folders.

Export

Save any frame's stretched view as a full-resolution PNG, JPEG or TIFF for quick sharing.

FITS Viewer is for browsing and sorting - it doesn't stack or process data. Use it before your processing software, not instead of it.

What's new in v1.4.0

Browsing

  • Folders full of subfolders now show folder tiles - each with a preview of the first image inside and a count of what's in it. Double-click to open; new Up button (Alt+Up) to go back.
  • Select several images with Ctrl+click / Shift+click, then press Ctrl+Space to open each in its own window.
  • Left/Right arrow keys flick between images in the full-size view.

Seestar and colour cameras

  • Stacked Seestar images and raw colour-camera sub-frames now show in full colour.
  • Field of view is now shown for files without a plate-solve, estimated from focal length and pixel size.

Cleaner thumbnails

  • Thumbnails are now made by averaging pixels instead of skipping them - much smoother, with far less speckle on star fields.

Deleting

  • Fixed: "Delete Marked Files" failed on Windows with "The system cannot find the path specified".
  • Whole folders can now be marked and deleted, with a confirmation that lists exactly what's inside.
